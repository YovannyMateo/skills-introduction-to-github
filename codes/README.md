# Code Examples

This directory contains simple code examples in various programming languages.

## Files

- **hello.py** - Python example
- **hello.js** - JavaScript example
- **Hello.java** - Java example

## Usage

Each file demonstrates a simple "Hello, GitHub!" program in different programming languages.

### Python
```bash
python3 codes/hello.py
```

### JavaScript (Node.js)
```bash
node codes/hello.js
```

### Java
```bash
javac codes/Hello.java
java -cp codes Hello
```
